# 湛卢 PDF · 首版产品定义

状态：**首版产品目标与验收基线**，已整合截至 2026-10-27 的有效交接决定；**v0.2（2026-10-31 用户决定）新增：OFD 打开与预览（转 PDF 另存）、PDF → Word/Excel/CSV/PPT 基础版导出、全屏预览与放映**。Figma：[湛卢 PDF · 视觉系统与完整场景](https://www.figma.com/design/LAdU272mtZ2RG2ZnQaGKX6)。本文件描述必须交付的产品，不代表现有程序已经完成或通过验收。

## 产品承诺

首版让用户在一台 Windows 电脑上，断网也能完成「打开 PDF → 阅读或整理页面 → 转换或用本地 AI 理解 → 检查并保存新文件」。主安装包启动和阅读不依赖 AI 模型；OCR 与本地模型可按需安装，但**首版交付必须提供可安装、可验证的离线能力包**。远程模型仅供用户明确配置和确认后使用。

“完整替代 WPS PDF”是产品长期方向，不是首版已经覆盖所有 PDF 能力的宣传语。首版验收以本目录为准；批注、内容编辑、签章、表单和云同步不在首版。

## 信息架构

全局：**顶部工作标签、查找功能、任务和设置**。首页及实际打开的 PDF、合并、拆分和独立转换任务各占工作标签，不预设空任务标签。当前 PDF 的文档模式为**阅读、页面、转换**；首页和独立任务页不显示文档模式。AI 阅读从阅读工具栏或右下入口打开当前 PDF 的右侧非模态 Chat，不创建 AI 标签，也不改变当前模式、页码或缩放。无当前 PDF 时先选择文件，已打开的 PDF 复用原标签。合并、拆分和转换可从首页建立独立任务；结果由用户决定是否打开。

PDF 与任务标签随可用空间等宽缩窄；放不下时通过“全部标签”下拉访问，当前标签保持可见，顶栏不显示横向滚动条。该规则以[用户重申后的交付记录](../../../.handoff/global-actions-delivery-2026-10-27.md)为准，覆盖旧交接词和画板中标签固定宽度、横向滚动的示意；设计图层与交接词的同步状态不代表发布验收通过。

| 能力 | 首版必须可用 | 交付边界 |
| --- | --- | --- |
| 阅读 | 本机 PDF、多标签、最近文件、密码输入；连续/单页、缩略图、目录、全文搜索、页码与缩放、适应宽度、视图旋转、复制文字、打印；恢复每份文档的位置；**v0.2：打开 OFD 并自动转换为 PDF 预览（可全屏预览、放映）** | 损坏或受限文件给出可恢复提示；扫描页提示 OCR；OFD 预览横幅标注转换性质，电子签章暂不渲染 |
| 页面 | 拆成单页、按第 N 页后分割、每 N 页、自定义范围；多 PDF 合并、拖动排序、逐份取页；页面重排、旋转、删除；输出预览并另存 | 首页入口是独立任务页；源文件不覆盖；OFD 无页面整理 |
| 转换 | PDF → PNG/JPEG、PDF → Markdown、PDF → TXT；多张 PNG/JPEG → 单个 PDF；范围、顺序、名称、位置、进度和结果；**v0.2：PDF → Word/Excel/CSV/PPT 基础版（文字流/表格提取/图片模式）；OFD → PDF 另存** | 图片、Markdown、TXT 使用各自上下文；Markdown 按可识别文字层生成基础标题与列表，复杂版式须核对；Office 导出为基础版定位（Word 文字按页整理、PPT 每页幻灯片图片、Excel/CSV 依赖检测到的表格），入口在独立转换任务页 |
| 全屏与放映 | **v0.2 新增**：阅读内全屏预览（隐藏界面沉浸阅读）；放映模式（墨黑底单页居中、键盘/滚轮翻页、可选自动播放） | Esc 退出并回到原页；OFD 预览同样可用 |

AI Chat 提供总结、提炼、分析等操作；输入区用同一入口选择已配置模型和该模型支持的思考强度，选择不发送内容、不清草稿。来源可跳回原 PDF 页。设置按“模型与 AI、文字识别、文件与输出”组织；远程配置保存在本机，连接检测不发送 PDF，默认模型设置不代替逐文档发送确认。

## 共同行为

1. 首页可打开一个或多个 PDF，也可从转换、合并、拆分入口先选文件并建立独立任务。转换接受单份 PDF 或多张图片，合并至少两份 PDF，拆分一份 PDF；AI 从全局气泡进入，无当前 PDF 时先选择一份。重复打开同一文件时复用已有标签。
2. 生成文件前核对输入、页序或范围、预计数量、文件名和保存位置。转换与合并可选择应用默认目录、源文件同目录或手动选择目录；**任何保存位置遇到同名一律在扩展名前自动追加（1）（2）等编号（v0.2 用户决定，覆盖旧的“其他位置提示处理”），最终结果显示实际名称**。位置不可用、不可写或页码错误时保留设置并提供恢复操作；任何情况下均不覆盖已有文件。
3. 默认生成新文件。取消、失败或程序重启不把半成品当作完成结果；任务列表可查看进度、取消、失败原因、重试及已完成文件。
4. 当前 PDF 的转换在原文右侧核对；AI Chat 为右侧非模态浮层，可关闭且不改变工作模式。切换或关闭面板保留页码、缩放和阅读状态。从首页进入转换、合并或拆分时建立独立任务标签。完成结果可打开阅读、打开所在位置或留在当前工作区。
5. 离线时阅读、页面、基础转换、OCR 和本地 AI 均可运行。OCR 由用户主动触发并生成可搜索副本；远程 AI 不作为本地能力失败后的自动回退。
6. 全局“查找功能”搜索命令与最近文件，与 PDF 内“查找文字”分开；任务入口反映真实任务状态。界面以清晰操作和状态代替重复解释，保留必要的错误、OCR、输出和隐私信息。

## 非目标

首版不提供批注、修改 PDF 原有文字/图片、签名、表单填写、云同步、压缩/加密工作台。**v0.2 口径**：OFD 仅支持打开、预览与转 PDF 另存（PDF→OFD 暂不做）；Office 仅支持 PDF → Word/Excel/CSV/PPT 基础版导出（Office→PDF 与复杂版式还原暂不做，后续可加 AI 增强）。隐藏未验收格式的操作入口；设置中可以显示未来能力，但必须标明不可用及原因。
