# 首版交互流程与状态规则

本文描述首版目标，不表示现有程序已经实现或通过验收。界面视觉以[现行设计](../../design/mvp-v1/README.md)为准；新确认的产品规则优先于历史交接中的旧方案。

## 0. 通用文件选择

入口：工作台快捷工具、阅读页上传、任务页继续添加。工作台快捷工具每次建立**新的选择会话**，不会偷偷使用上次阅读的文件。

| 入口 | 文件约束 | 选中后 |
| --- | --- | --- |
| 阅读 | 可一次选择多份 PDF | 每份打开为独立标签，首个文件激活并定位上次阅读位置；重复打开同一文件复用已有标签 |
| 拆分 | 1 份 PDF | 进入独立拆分设置页，不载入阅读画布 |
| 合并 | 至少 2 份 PDF；可继续添加 | 进入独立合并设置页，按选择顺序排列 |
| 转换 | 1 份 PDF，或多张 PNG/JPEG；不可混选 | PDF 进入导出设置；图片进入缩略图排序 |
| AI 阅读 | 1 份 PDF | 已打开则复用其阅读标签，否则创建一个 PDF 标签；在其中展开 AI 右侧栏并展示本地/远程通道状态 |

选择弹窗可拖入文件或从本机选取，并列出名称、页数/尺寸和移除按钮。加密 PDF 在打开或读取页数时请求密码；错误后可重试或取消。损坏、无权限、超出大小限制或不支持格式时说明具体原因。

顶部只展示实际打开的首页、PDF 和文件处理任务，AI 不创建标签。PDF 与任务标签根据可用宽度在 208–104 px 间等宽缩放；仍放不下时，按 104 px 宽度保留可见项，其余可从“全部标签”下拉选择，当前项始终可见，顶栏不出现横向滚动条。下拉列出全部标签并标识当前项，切换后保持工作区状态与焦点可达；首页、打开文件和全局操作在窄窗口仍可访问。右键实际工作标签提供关闭该标签、其他、左侧、右侧及全部，目标按被右键标签和所有打开标签的逻辑顺序确定；空白处只提供关闭全部。无目标的操作禁用。涉及未保存更改时先提示并允许取消；关闭任务标签不取消运行中的任务。当前项被关闭后优先切到右侧相邻项，再左侧，无剩余工作标签时返回首页。菜单可用键盘操作并恢复焦点。

顶部“查找功能”搜索应用命令及最近文件，与 PDF 正文“查找文字”分开。空查询分组展示可用命令和最近文件，有当前 PDF 时优先显示其操作；打开即聚焦输入框，结果列表限高滚动，方向键选择、Enter 执行、Esc 关闭并恢复原焦点。输入法组字时 Enter 不执行命令。

## 1. 阅读

`首页/最近文件/结果 → 加载与密码检查 → 文档页 → 搜索或切换模式 → 关闭/重开恢复`。

- 默认连续阅读，左栏在缩略图、目录、搜索间切换。每份文档保存当前页、缩放、连续/单页、左栏状态；切标签和重启后恢复。
- 页码框只接受 1 到总页数，失焦或回车跳转；无效输入恢复原页并提示。目录和搜索结果点击后定位页，搜索词在文字层高亮。页内视图旋转与文件旋转分开，文件旋转必须通过页面模式另存。
- 有文本层时可选区复制并直接送入 AI 解释/翻译；整页复制是辅助入口。无可选文字时提示 OCR。打印只发送用户当前选择的文档，必要时先输入打开密码。
- 加密文档不保存明文密码。若搜索、缩略图、目录或打印能力受限制，应显示原因，而不是留下空白控制区。
- 文档模式仅有阅读、页面和转换；阅读工具栏和右下气泡均打开当前 PDF 的同一 AI Chat。Chat 非模态，不压缩原文、不建立标签，关闭时保留草稿、页码、缩放及模式并恢复焦点。两个入口共享会话，切换文档不得串用回答或迟到结果。页面有未应用更改时，打印前须说明打印的是已保存版本或引导先另存。

## 2. 拆分

`选择 1 份 PDF → 选择规则 → 实时预览输出 → 名称与位置 → 生成 → 完成页`。

| 规则 | 输入 | 预览与输出 |
| --- | --- | --- |
| 拆成单页 | 无 | N 页生成 N 份，每份 1 页 |
| 按某页分割 | 第 N 页后，1 ≤ N < 总页数 | `1–N` 和 `N+1–末页` 两份 |
| 每 N 页 | 1 ≤ N ≤ 总页数 | 连续分组，最后一份可少于 N 页 |
| 自定义范围 | 例如 `1-5,6-12,13-24` | 每个区间生成一份，顺序与输入一致 |

预览列出文件数、每份页码与输出名称；超过可见数量时显示总数和可滚动清单。页码越界、空范围、重叠或遗漏页给出明确提示：自定义范围允许用户故意只导出部分页，但应标注未导出的页。生成时显示当前文件数/页数和取消按钮。完成后可打开任一结果为新标签，或打开输出位置。

## 3. 合并与页面整理

合并：`选择多份 PDF → 拖动/上下移动 → 每份选全页或指定页 → 核对总页数与顺序 → 名称与位置 → 生成 → 完成页`。文件卡片可移除；至少两份有效 PDF，至少一页输出。预览应显示实际将写入的页顺序。拆分与合并共享输出核对和任务状态，但同名处理按第 6 节的任务及位置规则区分。

页面整理：在阅读中选中一页或多页，可拖动重排、左/右旋转和删除。右侧实时列出顺序、旋转与删除摘要；保存为新 PDF，原文件保留。全删、受保护文件、不允许修改的权限和非法页范围必须阻止执行，并说明原因。

## 4. 转换

PDF 输入：选择一份 PDF → 选择图片、Markdown 或 TXT → 选择全部或自定义页码，阅读内转换还可选当前页 → 设置名称与位置 → 核对输出数量和文件名 → 执行。当前 PDF 的原文保持可读，转换设置在右栏；首页发起则进入独立任务。图片仅提供 PNG/JPEG 和 96/150/300 DPI，每页一张并按原页码命名，例如 `文件名-p003.png`；Markdown 与 TXT 各生成一份所选页的文本文件，TXT 保留页分隔，Markdown 仅承诺可识别的基础标题和列表。扫描页无文字时提示先 OCR，不将空正文伪装成成功。

切换目标时，标题、格式、预览与实际输出保持一致；保留有效页范围、名称和位置，图片格式及清晰度可在返回图片时恢复。无效范围或预览失败时禁用开始并说明原因；旧预览和已提交任务的结果不得串入新的目标或文档。

图片输入：选择至少一张 PNG/JPEG → 显示每张缩略图、序号、名称、尺寸 → 拖动或用上下移动按钮排序，可移除 → 显示结果 `1 个 PDF / N 页` 和当前顺序 → 命名/选位置 → 生成。删除与排序只影响本次任务，原图不变。结果页可以直接打开新阅读标签。

## 5. AI 与 OCR

AI 右侧栏不创建新标签，始终标明当前文档、模型所在位置和本次内容范围；关闭侧栏保留当前页、缩放与阅读状态。本地模型未安装时提供安装/检测步骤；安装失败可重试，阅读与非 AI 工具继续可用。模型与思考强度在同一入口中选择，仅显示真实可用模型和其支持的离散强度；切换保留草稿，不自动发送，不改变已提交请求。用户主动配置远程模型时，摘要发送可提取的全文片段，问答发送检索页文字，选区操作只发送选中文字；每份文档首次使用对应远程连接前确认目标、操作和实际范围，取消不发送。保存配置、检测连接和设默认均不代替确认；远程模型不作为本地失败后的自动回退。

摘要覆盖全文且标明处理页数；问答展示答案、来源页和截取片段。点击来源回到 PDF 对应页；只有获得可靠文字坐标时才高亮选区，否则只定位到页并明确说明。无法找到依据时显示不确定，不能伪造页码。

扫描 PDF：检测无文字层 → 提示离线 OCR → 用户主动发起 → 展示逐页进度、取消与重试 → 生成保留原图的**可搜索 PDF 副本** → 用户可搜索、复制并打开新标签。转换工具栏、全局查找的当前 PDF 命令、转换提示和 AI 无文字错误处均提供 OCR 入口。OCR 文字与源页码逐页对应；低置信度或识别失败页可查看和重试。识别后不自动重发 AI 请求，用户检查结果后再主动发起；仍无可提取文字时如实提示。

## 6. 输出与任务状态

默认保存到应用输出目录；转换（含图片转 PDF）及合并还可选“与源文件同目录”或通过系统文件选择器选择其他目录。单文件按该文件实际目录，多文件按当前列表第一项的实际目录；排序或移除改变首项时刷新目录及预览。源文件真实目录不可得或不可写时保留选择、说明原因并引导选择其他位置，不能把上传临时副本当作源目录或静默回退。

转换与合并选同目录时，已有同名则在扩展名前追加 `（1）`、`（2）` 等编号，预览展示预计文件名；交付时再次处理新出现的冲突，完成态展示实际名称和位置，任何情况下均不覆盖已有文件。应用默认目录、手动位置及拆分等其他任务仍遇同名提示更名、换目录或取消。多输出逐项避免本批次及磁盘冲突；取消、失败或中断仅清理本任务产物，不删除原文件或已有文件。

任务状态为 `待执行 / 运行中 / 取消中 / 已完成 / 失败`；任务入口显示真实运行和取消中数量。失败后保留输入、顺序、页码、目标和名称；程序异常退出后可查看未完成任务及恢复操作，清理安全的临时文件。进度只反映真实处理情况；未知进度不伪造百分比，处理到 100% 后仍以实际完成为准。清理终态任务记录不删除生成文件或运行中的任务。

键盘操作：Tab 可到达所有输入、列表和按钮；拖动排序都有上移/下移替代；Enter 提交，Esc 关闭弹层。窄窗口 840 px 下保留翻页、缩放、搜索、复制、打印和 AI。错误信息放在相关设置旁，颜色之外也使用文字和图标区分。
