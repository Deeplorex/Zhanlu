## 性能与质量记录（参考机：开发机 i7/32GB/SSD）

- 1000 页文本 PDF：首屏 222 ms（目标 5 s）；页码跳转 ≈1.3–1.6 s；搜索 24 页全量 <3 s。
- OCR：约 2.3 s/页（200 dpi，含渲染+识别+文字层回写）。
- 本地模型（qwen2.5:3b，CPU）：全文摘要（24 页单块文档）15 s；单问 23–26 s。
- 桌面安装包 109.6 MB；sidecar 进程内存 ≈100 MB 常驻。

## 未完全自动化 / 遗留项（如实记录）

1. **R04 打印实际出纸**：已改为湛卢内置打印，打印 PDF 的页数、纸张尺寸、内容和权限已验证；WebView2 系统打印窗口与真实打印机输出需人工复核。
2. **S02 干净机器**：本机为开发机；安装目录与运行已确认零仓库依赖，建议发布前在虚拟机/新系统复跑本表。
3. **加密文件徽标**：服务端无密码时读不出 encrypted 元数据，阅读器不显示“已加密”徽标（打开/密码流程正常）。
4. **远程 AI 逐文档确认**：引擎强制 + UI 确认框已实现，未连接真实远程 key 走完整链路（无 key 可用）。
5. **PDFium 崩溃面**：已对缩略图做每文件串行锁；任务内渲染各自持有独立文档对象。极端损坏文件仍可能崩引擎进程，后续可做进程隔离（架构评审 P1 事项，v1 已大幅缓解）。
