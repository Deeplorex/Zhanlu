# 湛卢 V2｜完整 PDF 工作台设计

> 历史设计探索。第一个 MVP 的现行范围以[产品定义](../../product/mvp-v1/README.md)为准，逐屏以[Figma 索引](../mvp-v1/README.md)为准；首版导航已收敛为阅读、页面、转换、AI 四个模式。

## 产品目标

替代日常使用 WPS PDF 的完整工作流：打开、阅读、批注、编辑、组织页面、转换、签署、保护，以及在文档内直接使用 AI。默认离线、本地保存、启动快；用户主动选择远程模型时才传送明确选中的内容。

界面默认采用第三套“湛卢墨色”：墨黑主色（`#2B2622`）、白色纸张、暖白工作区，少量暖色作为非主色细节。[松溪县湛卢文化资料](https://www.songxixww.com/2017-12/26/content_243436.htm)将“湛卢”的色彩意象与厚重纯黑联系起来；这里的色值是设计转译，不是对传说中原剑的实物取样。

对标范围依据 [WPS PDF 官方功能页](https://www.wps.com/office/pdf/)：阅读、编辑、转换、压缩、签署，以及摘要、翻译、解释选区和文档问答。湛卢的差异是**把这些工作放在同一个文档视图里**，不让用户反复离开文档去找“中心”或“工具箱”。

## 一条主路径

`打开文件 → 阅读 → 选中内容或切换任务 → 预览改动 → 保存 / 另存为`

- **首层只有文档标签与六个任务模式**：阅读、批注、编辑、页面、转换、AI。切模式时保留当前页、缩放和选区。
- **第二层是当前任务的常用命令**：最多 5–7 个，不在工具栏摆满全部能力。扩展能力从“更多工具”进入，并可用 `Ctrl+K` 搜索。
- **左栏负责定位**：缩略图、目录、搜索结果三选一；可隐藏。右栏负责当前工具的属性或 AI 对话；默认关闭。
- **中央只放文档**：连续滚动优先，单页/双页可切换。状态栏放页码、缩放和保存状态。
- **AI 不抢占阅读界面**：选中文字后出现“解释 / 翻译 / 询问”；无选区时从右栏做摘要、问答、OCR。回答必须能跳回证据页。

## 完整能力结构

| 模式 | 直接可见的主要动作 | “更多工具”中的能力 |
| --- | --- | --- |
| 阅读 | 页面/目录/查找、缩放、适应宽度、打印 | 单双页、连续/逐页、夜间阅读、对比文档、朗读、文档属性 |
| 批注 | 高亮、下划线、便签、文字框、画笔 | 形状、图章、批注列表、导入导出批注、回复与筛选 |
| 编辑 | 改文字、插入图片、链接、裁剪 | 字体与段落、背景、水印、页眉页脚、编号、表单字段 |
| 页面 | **拆分、合并**、提取、重排、插入、删除、旋转 | 替换、统一尺寸、批量页范围 |
| 转换 | Word、Excel、PPT、图片、OFD | 文本/Markdown、HTML、批量转换、压缩、加密、解密、隐私清理 |
| AI | 摘要、问答、翻译、OCR、表格提取 | 生成目录、解释选区、术语提取、跨文档问答、版式修复 |

签名与表单作为“编辑”的明确入口；压缩与保护在“转换”的交付动作内，也能通过命令搜索直达。用户无需先理解底层引擎。

## 关键状态和操作规则

1. **打开**：多文档标签。关闭未保存标签时提示保存、丢弃或取消；重开应用恢复标签和阅读位置。
2. **编辑**：对原文件建立本地工作副本，所有命令进入统一撤销栈。页面变化先预览再应用；`Ctrl+S` 保存，首次编辑也可另存为。
3. **耗时任务**：转换、OCR、AI 翻译进入右上角任务队列。文档继续可读；完成后提供打开结果、定位输出和重试。队列可取消并可在重启后找回。
4. **能力不可用**：命令保留可发现性，点击后说明缺少什么、可用替代和安装/配置入口；绝不先执行再报“引擎未装”。
5. **AI**：本地模型是默认通道。远程模型由用户自行配置；首次对某文档使用时显示将传送的范围与服务商，之后在 AI 栏持续显示当前通道。AI 对源文件只生成建议或新副本，不直接覆写。
6. **证据**：AI 回答标页码；摘要和表格结果可点回原页。没有可验证依据时明确表示不确定。
7. **OFD**：与 PDF 同样能阅读、定位、搜索和打印；编辑能力若由转换副本实现，要在保存前显示格式变化。
8. **拆分**：提供“拆成单页”“在第 N 页后分割”“每 N 页”“自定义范围”四种方式，实时列出输出文件及对应页码。按某页分割明确生成 `1–N` 和 `N+1–末页` 两份；自定义范围允许指定多个区间。输出为新文件，原件保留。交互参考 [WPS 的按页数与自定义范围拆分](https://www.wps.cn/learning/course/detail/id/12189?sid=697)和[逐页拆分](https://www.wps.com/academy/how-to-save-each-pdf-page-as-separate-files-quick-tutorials-1862285/)。
9. **合并**：直接在“页面”模式进入。加入多个文件后，可上移、下移、移除文件，并为每份文件指定页码范围；预览合并后的总页数，再填写输出文件名和保存位置。原文件不变。交互参考 [WPS 的合并文件和页范围设置](https://www.wps.cn/learning/room/d/268850)。

## 速度与本地架构原则

- 窗口先打开，文档渲染和能力探测并行。首屏不等待 Office、OCR 或 AI 引擎扫描。
- 只渲染视口附近页面；缩略图、文本索引和搜索结果增量生成并按文档指纹缓存。
- 文档读取、渲染、编辑、转换、OCR、AI 是独立工作任务。损坏文档不能使整个窗口退出。
- 本地文件访问由桌面壳授权，处理进程通过受保护的会话通信；不让普通网页调用任意本机文件路径。
- AI 提供统一能力接口：本地推理、用户自配远程模型、OCR 与检索共用文档索引。选择模型不改变用户操作路径。

### 为“轻量 + 本地 AI”作出的产品取舍

基础安装包包含阅读、批注、页面操作和核心 PDF 引擎；OCR、Office 格式转换与本地大模型作为**按需安装的能力包**。功能入口仍在原位，首次使用清楚显示包大小、安装位置和离线可用状态。这样才能让日常打开 PDF 保持轻快，同时允许需要完整 AI 的用户一次安装后离线工作。远程模型是可选通道，不是本地能力缺失时的隐形回退。

### 引擎边界

| 组件 | 职责 | 失败时的用户体验 |
| --- | --- | --- |
| 桌面宿主 | 文件授权、窗口与标签、更新、任务通知、安全会话 | 清楚显示引擎状态，仍可访问最近文件 |
| 文档核心 | PDF/OFD 解码、渲染、文本层、注释、编辑事务、撤销/重做 | 隔离当前文档的错误，不关闭整个应用 |
| 处理工作进程 | 转换、压缩、OCR、索引、批量任务 | 可取消、重试；保留输入和失败原因 |
| AI 服务 | 本地模型或显式选定的远程模型、检索、来源页映射 | 无模型时阅读与非 AI 工具照常可用 |

必须选用能支持真正内容编辑、表单、签名和注释写回的文档引擎；只组合阅读渲染器与页面拼接库，无法满足“完整替代”的目标。具体引擎应先以真实中文合同、扫描件、复杂表格和签名文档做兼容性与许可证评估，再决定。

## “完整替代”的验收线

- **阅读**：长文档、加密文件、扫描件和 OFD 能稳定打开；定位、搜索、复制、打印与多标签恢复可靠。以至少 1000 页文档验证内存与滚动响应。
- **修改**：批注、文字/图片/链接编辑、页面整理、表单填写与签名能保存并被其他主流 PDF 阅读器正确打开；每次修改可撤销，崩溃后可恢复草稿。
- **交付**：PDF 与 Office/图片/OFD 的主要转换、压缩、密码保护与批量任务有可观察进度、质量选项和失败恢复。输出前可预览质量和格式变化。
- **AI**：本地 OCR、摘要、问答、翻译和表格提取在离线环境可用；回答能跳回来源页，输出有审核步骤，远程发送必须由用户明确选择。
- **质量**：上述流程用真实中文材料、不同编码与字体、扫描件及损坏文档回归；兼顾键盘操作、读屏可访问性和高 DPI 窗口。

## 当前交付边界

`palette.html` 提供四种配色的同屏对比；`index.html` 是可点击的设计原型，包括拆分结果预览、合并文件顺序与页码范围设置，用来确认操作路径。它尚未生成真实 PDF，也未实现 PDF 编辑或 AI 推理。现有代码的引擎和功能需要按本设计重新接线、补齐和验收，尤其是页面拆分/合并写入、批注、真正的内容编辑、签名表单、完整 OFD 阅读、持续任务与本地 AI。
