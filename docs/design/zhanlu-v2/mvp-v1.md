# 湛卢 PDF · 第一个 MVP（历史草案）

> 现行首版范围、流程与验收已经迁至 [产品定义](../../product/mvp-v1/README.md)。此文件保留早期决定供回溯；完整画板见 [Figma 索引](../mvp-v1/README.md)。

## 目标与边界

首版验证一条完整的本地 PDF 工作路径：**打开并阅读 → 整理页面或转换 → 用 AI 理解内容 → 检查结果并保存新文件**。产品导航只有 **阅读、页面、转换、AI** 四个模式。文档始终位于中央，切换模式保留当前页、缩放和左侧导航状态。

首版不提供批注、修改 PDF 原有文字和图片、签名、表单、OFD、复杂 Office 双向转换或云端同步。隐藏这些入口，不用不可用按钮占据工具栏。后续版本再依据真实使用频率和引擎成熟度决定加入顺序。

## 跨模式规则

1. **本地优先**：默认仅访问用户打开的本机文件。首次使用 AI 时明确显示“本地”或用户自行配置的远程通道；远程发送前展示内容范围。
2. **不破坏原件**：拆分、合并、转换和 OCR 都生成新文件。执行前显示页范围、文件数、输出名称和路径；结束后可打开结果或定位文件。
3. **长任务不中断阅读**：转换、OCR 和 AI 进入任务队列，展示进度、取消、失败原因与重试。任务运行时仍能翻页和搜索。
4. **简单入口**：顶部只有四个模式；第二层只放当前模式最常用的 4–6 个动作；其余功能用“查找功能”直达。
5. **结果可核对**：拆分/合并先预览页序；转换可查看输出摘要；AI 引用点击后返回源页。无法定位依据时明确说明。
6. **首页快捷入口先选文件**：点击「转换 / 合并 / 拆分 / AI 阅读」均先打开选文件弹窗；转换可一次选择多张图片，拆分与 AI 阅读选择一个 PDF，合并可连续添加多个 PDF。选择完成后才进入对应工作区，不直接使用上次打开的文档。弹窗明确标注“文件仅在本机处理”。
7. **首页处理任务不强制阅读**：首页进入合并或拆分时使用独立任务页，顺序、页范围、名称、保存位置和预览全部在这里完成，不加载阅读画布。完成后才提供「打开结果并阅读」；点击后在新文档标签中打开。阅读过程中进入页面工具则可使用文档上下文。

## 关键流程

### 拆分

首页「拆分」→ 弹窗选择一个 PDF → 独立拆分任务页 → 选择「拆成单页 / 在某页后分割 / 每 N 页 / 自定义范围」→ 查看输出文件数和页码 → 设置文件名前缀与保存位置 → 生成 → 完成页，可定位文件或打开任一结果进入阅读标签。  
「在第 N 页后分割」输出 `1–N` 与 `N+1–末页` 两份；边界页不能填 0 或末页。

### 合并

首页「合并」→ 弹窗选择多个 PDF → 独立合并任务页，可继续添加文件 → 拖动调整顺序及各文件页范围 → 查看输出页数与顺序预览 → 设置输出文件名和保存位置 → 合并 → 完成页，可定位文件或打开结果进入阅读标签。源文件保持不变。

### 多张图片转 PDF

首页「转换」→ 弹窗一次选择多张 PNG/JPEG，或在转换页继续添加 → 以缩略图卡片预览全部图片，卡片序号代表 PDF 页码 → 拖动排序或用上移/下移按钮调整，移除不需要的图片 → 查看页数与文件顺序 → 设置 PDF 文件名、保存位置 → 生成一个 PDF → 完成页可下载、定位文件或打开新的阅读标签。添加不同文件类型时给出提示，不把 PDF 和图片混入同一批次；删除和排序不会改动原图。

### AI 问答

阅读时切换 AI → 选择本地模型 → 提问 → 查看带页码的回答 → 点击来源跳转并高亮对应原文。扫描件先提示 OCR，可在同一侧栏启动。

## 验收场景

- 1000 页 PDF 可打开并持续翻阅；搜索、缩略图和页码定位不阻塞首屏。
- 24 页 PDF 在第 3 页后拆分，预览与产物分别为 3 页、21 页；拆成单页得到 24 个文件。
- 两份 PDF 选取不同页范围合并，输出顺序和页数与预览一致，原文件不变。
- 一次选择至少 3 张图片，交换首末顺序并删除其中一张；转换前显示 2 张缩略图与对应页序，产出的 2 页 PDF 与预览一致，原图不变；完成后可在新阅读标签打开。
- PDF 图片/文本转换、图片转 PDF 在完全离线时完成；长任务可取消并重试。
- 扫描版中文 PDF OCR 后可搜索；AI 答案的来源页可跳转，断网时本地 AI 可用。
- 多标签切换保留页码与缩放；应用重开恢复最近文档和阅读位置。
