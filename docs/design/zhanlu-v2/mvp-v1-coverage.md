## 执行规则

1. **原件不覆盖**：所有页面处理、转换和 OCR 产物均另存。执行按钮前固定展示来源、页序或页范围、输出数量、文件名、保存位置。
2. **预览即结果**：合并源文件的顺序和页范围、多图转 PDF 的缩略图序号，必须与输出页序一致。移除源项只修改当前任务。
3. **任务可恢复**：运行中展示已完成页数；失败展示原因，并保留源文件、顺序、页范围和输出设置供重试。取消后不登记半成品。
4. **远程 AI 明示**：本地模型使用本机地址；远程摘要会分段发送文档可提取文字，问答发送匹配页文字。每次切换文档后重新确认。来源页只链接到实际输入文档页。
5. **四模式导航**：顶部仅阅读、页面、转换、AI；首页和设置作为全局入口。实验性的 OFD、表格提取、加密及 Office 双向转换不占首版导航。
6. **键盘与窄窗口**：输入框、页码、按钮和文件列表均可用键盘操作；窄窗口保留翻页、搜索、复制、打印和 AI 入口，不隐藏关键操作。

## 首版发布验收

设计覆盖的是目标行为，**不等于运行程序已全部实现**。以下测试全部通过后才可称为“首版完全可用”：

| 验收场景 | 必须核对的结果 |
| --- | --- |
| 1000 页 PDF | 首屏可用；连续滚动、缩略图和全文搜索不阻塞；多标签切换与重开恢复页码、缩放 |
| 24 页 PDF 第 3 页后拆分 | 预览 3 + 21 页，实际生成两份且页数一致；拆成单页得到 24 份；源文件不变 |
| 两份 PDF 取不同页范围合并 | 拖动顺序、页范围、总页数、实际产物完全一致；结果可新建阅读标签 |
| 三张图片转 PDF | 移动首末顺序并删去一张；预览两张与产物两页同序；文件名、保存位置、原图不变 |
| PDF 转 PNG/JPEG/TXT | 选择页范围与目标位置；能取消、失败后重试；结果可打开或定位 |
| 扫描版中文 PDF | 离线 OCR 生成可搜索 PDF，搜索与复制可用 |
| AI 摘要与问答 | 离线本地模型可用；引用页可跳回原文；远程模型须经过内容范围确认 |
| 桌面安全与恢复 | 仅授权文件可被读取；任务中断可恢复；模型密钥由系统凭据库保存；安装包可在离线机器运行 |

当前实现状态与尚缺能力见[技术架构与发布门槛](../../architecture/mvp-v1.md)。
