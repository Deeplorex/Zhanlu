# 湛卢 Zhanlu · 玄铁 UI 开发交接规格

版本 v1.0 ｜ 2026-10-23 ｜ 配套高保真稿：同目录 `tokens.html`、`s1-home.html` … `s7-engines.html`（1280×900，可直接浏览器打开）｜ 方向选择记录：`../style-round-01/notes.md`

---

## 1. 方向

- **北极星**：深夜书房里一柄玄铁剑横在工作台上——安静、锋利、可靠。湛卢是握在手里的利器，不是热闹的玩具。
- **结构语法**：76px 剑脊竖导航（顶部 CSS 剑形标识 + 图标导航 + 版本号）贯穿全部界面；其余区域按「面板 + 描边 + 明度分层」组织，不靠色相和重阴影分层。
- **色彩纪律**：唯一强调色「剑光青」`#6FB6C8`，每屏实心青面积 ≤10%（主按钮每屏只允许一个青底）；状态色仅做语义：`--ok` 就绪/完成、`--warn` 未安装/注意、`--danger` 加密/错误。
- **品牌时刻**：文档卡悬停，一道 115° 斜向青光扫过封面（见 §5 动效）。

## 2. 设计变量（可直接复制为全局 CSS）

```css
:root{
  /* 表面 */
  --bg:#0B0F13;        /* 应用底 */
  --panel:#12181F;     /* 面板 / 导航 / 卡片底 */
  --panel-2:#161E26;   /* 浮起 / 输入底 / 悬停 */
  --canvas:#0E1319;    /* 阅读画布（比 bg 略亮，衬托白纸） */
  --line:#232D37;      /* 描边 */
  --line-hi:#33434F;   /* 描边·悬停 */
  /* 文字（四级） */
  --ink-hi:#E4EDF3;    /* 屏幕标题 */
  --ink:#C9D5DF;       /* 正文 / 控件文字 */
  --ink-2:#84929F;     /* 次要说明（正文最低允许级） */
  --ink-3:#586673;     /* 仅限等宽标签与禁用态，不承载必要信息 */
  /* 强调与状态 */
  --glow:#6FB6C8;      /* 剑光青·主强调 */
  --glow-soft:rgba(111,182,200,.12);
  --glow-line:rgba(111,182,200,.45);
  --ok:#6FA98C;  --ok-soft:rgba(111,169,140,.12);
  --warn:#C2A15C; --warn-soft:rgba(194,161,92,.12);
  --danger:#C47A6E;
  /* 字体 */
  --sans:'Segoe UI','Microsoft YaHei',sans-serif;  /* 上线可换思源黑体 SC */
  --mono:'Consolas','Courier New',monospace;       /* 数字读数 / 状态词 */
}
```

- 字阶：22/600（屏幕标题，ls .1em）· 15/600（区块标题）· 14（正文/按钮）· 12.5（辅助）· 10.5 mono（标签/读数，仅英文与数字）。
- **字号红线**：中文正文与关键辅助信息 ≥12.5px；11px 以下只允许等宽的英文/数字标签（页码、耗时、版本号）。
- 间距 4px 网格：组内 8/12，组间 20/24/32。圆角：10 卡片 / 8 按钮输入 / 6–7 分段与小控件 / 4 徽章与 kbd。

## 3. 组件语法（一屏内必须同构）

| 组件 | 规格 | 状态 |
|---|---|---|
| 主按钮 | 青底 `--glow` + 深字 `#0B0F13` + 600 字重，高 38–40 | hover `#82C2D3`；按下 scale .97 |
| 次按钮 | `--panel-2` 底 + 1px `--line` 描边 + 8px 圆角 | hover 描边 `--glow-line` + 底 `--glow-soft` |
| ghost 按钮 | 透明底 + `--ink-2` 字 | hover 字变 `--ink` |
| chip 动作条 | 高 32–38 + 图标 1.4px 描边 + 可选 mono 快捷键 | 同次按钮 hover；选中 `.on` 青描边 |
| 输入框 | `--canvas` 底 + 1px `--line`，高 34–38 | 聚焦描边 `--glow-line` + 外扩 3px `--glow-soft` |
| 分段控件 seg | `--canvas` 底容器 + 选中项 `--glow-soft` 底 + inset 青描边 | 选中底板滑动 180ms |
| 开关 | 38×21 胶囊，开态 `--glow` 圆点 | 180ms 弹簧曲线 |
| 徽章 | mono 10.5px + 4px 圆角 + 1px 描边：格式类=青、ok=绿、warn=金、danger=赭 | — |
| 状态灯 | 7px 圆点：`--ok`（带 6px 光晕）/ 空心灰 / `--warn` | 可点击跳设置 |
| 文档卡 | 封面区 148px（渐变金属底 + 白纸预览 + 格式徽章 + 锁标） | hover 青描边 + 剑光扫过 |
| 剑脊导航 | 76px 宽，图标 46×46；选中：青字 + `--glow-soft` 底 + 左缘 2px 青条（带 8px 光晕） | 图标必须带 tooltip（title） |
| 进度刻度 ticks | 15×9px 连续格，进行=青、完成=绿 | 逐格填充 |
| 表格 | 表头 `--panel-2` 底 + `--ink-2` 字；数字右对齐 mono；合计行 `--glow` 字 | 行 hover `--glow-soft` |

图标：统一 1.4–1.5px 描边、直角端点（工业感），内联 SVG；上线建议选 **Radix Icons 或 Carbon**（15px 紧凑界面系），全站仅此一套。

## 5. 动效规格（金属咔嗒系）

| 名称 | 参数 | 用途 |
|---|---|---|
| 按下咔嗒 | `transform:scale(.97)` · 150ms · `cubic-bezier(.2,.7,.3,1)` | 所有按钮/卡片/chip |
| 剑光扫过 | `background-position` 110%→-10% · 550ms ease · 115° 渐变带 12–16% 青光 | 文档卡与封面悬停（品牌时刻） |
| 首次出场 | `translateY(6px)+淡入` · 每项 +50ms · 总长 ≤600ms · 仅首次 | 工作区先到、侧栏/列表随后 |
| 面板滑入 | `translateX` · 进入 250–350ms 减速；关闭 60% 时长加速 | 侧面板、抽屉 |
| 选中滑块 | 底板位移 180ms | 标签页/分段控件，禁止旧灭新亮 |
| 任务脉冲 | 呼吸 opacity 1→.35 · 1.6s | 进行中状态灯/队列徽章 |

无障碍：所有明显位移动效在 `prefers-reduced-motion` 下直接到位。

## 6. 国际化与命名

- 系统语言=中文 → 显示「湛卢」；否则「Zhanlu」。安装目录/进程名恒为 `Zhanlu`。标题栏：`湛卢` / `Zhanlu`；等宽装饰词（`ZHANLU READY` 等）恒英文。
- 文案双语对照示例：开始转换 Start Convert ｜ 继续案头 Recent ｜ 已连通 Connected ｜ 未安装 Not Installed ｜ 引导安装 Install Guide ｜ 纯本地 · 无遥测 Local-only · No telemetry。
- 全部文案走 i18n 资源（zh-CN / en），界面不允许硬编码。

## 7. 可访问性底线

- 对比度：正文 `--ink`/`--panel` ≈ 10.9:1，`--ink-2`/`--panel` ≈ 5.7:1（达标）；`--ink-3` 仅用于非必要装饰信息。
- 键盘：`Ctrl K` 搜索、`Ctrl 1–8` 工具矩阵（S3 设计已印快捷键）、`Ctrl+Enter` 开始转换、`Ctrl+Z` 撤销；全部可点元素 `:focus-visible` 青色 2px 外扩描边。
- 状态不允许只靠颜色表达：灯点+文字、进度+百分比、加密=锁图标+赭红字。

## 9. 实现注意事项（Tauri + Web 前端）

- 小样为纯 HTML/CSS + Alpine（`?state=` 切状态）；正式实现把 §2 变量放全局样式，组件按 §3 封装，Alpine 仅小样用，正式前端用所选框架重写交互。
- 深色阅读画布上 PDF 白页自带 `0 18px 50px rgba(0,0,0,.55)` 投影 + 后置错位纸边（S2 `.page-wrap::before`），保持「纸上暗桌」质感。
- 示例数据统一沿用「2026年度审计报告.pdf（86 页）」这一虚构文档贯穿各屏，演示互相呼应；上线后换真实最近文件。
- 截图证据：`shots/`（每屏 1280×900，S2/S3/S5 含交互态与并排图；report.json 记录了每次加载检查，仅 favicon 404 为无害噪音）。
