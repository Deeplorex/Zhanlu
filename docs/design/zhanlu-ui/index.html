方向 RECAP

北极星：深夜书房里一柄玄铁剑横在工作台上——安静、锋利、可靠；湛卢是握在手里的利器。
结构语法：76px 剑脊竖导航 + 面板分区；标题用字距与明度分层，不靠色相。
色彩纪律：墨黑金属底 + 寒银四级文字，唯一强调色「剑光青 #6FB6C8」每屏 ≤10% 面积；状态色三枚（青绿/暗金/赭红）只做语义。
品牌时刻：文档卡悬停时一道斜向剑光扫过封面——材质即识别。

动效 MOTION · 金属咔嗒

  • 按下咔嗒　scale .97 · 150ms · bezier(.2,.7,.3,1)　按钮/卡片按下立即生效
  • 剑光扫过　gradient position · 550ms ease　文档卡悬停 · 品牌时刻
  • 首次出场　rise 6px · 每项 +50ms · 总长 ≤600ms　工作区先到，侧栏随后，仅首次
  • 面板滑入　translateX · 250–350ms　从所在一侧滑入，关闭走 60% 时长
  • 选中滑块　180ms　标签页共用一块移动底板，禁止旧灭新亮
