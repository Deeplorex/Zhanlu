# 湛卢 UI 方向探索 · 第 01 轮

日期：2026-10-23 ｜ 视口：桌面 1280×900 ｜ 页面：工具箱首页（最高频入口）

## 用户任务与主动作

用户（自用的中文技术用户，Windows）打开湛卢首页要做三件事：**回到最近文档**、**发起一个高频动作**（转换 / 合并 / 拆分 / OCR / 提取表格 / 提取目录 / AI）、**确认引擎与 AI 状态**（Office 已连接？LibreOffice 装没装？AI 配了没？）。首页是"处理对象的页面"：内容先行，不放口号与解释段落。

## 品类与标杆

品类：桌面文档工具箱。拆了两家：

- **PDF Expert**（Readdle）：文档封面先行、控件轻（细描边、小圆角、单一蓝强调）、快捷动作悬停出现。理由：处理对象明确后动作才有意义。→ **沿用**：最近文档以封面卡/行呈现、控件克制。
- **Adobe Acrobat**：工具以"文字 + 短说明"呈现而非纯图标，快捷键印在界面上。理由：专业动作多，图标记不住。→ **沿用**（D 方向最明显）：工具带一句短说明。
- **WPS PDF 首页**：彩色大图标宫格 + 最近文件。→ **视为品类套路**，B 方向明确打破它。

品牌证据：湛卢为十大名剑之一，"湛卢"字面即深黑之水色，"仁道之剑"。深黑、寒光、文房、可靠——四个方向都从这条品牌线索出发，互不撞脸（不用 WPS 红、Acrobat 灰红、Foxit 蓝）。

## 差异检验记录

- 骨架：左导航网格 / 通栏目录 / 顶条+标签卡网格 / 仪表带+矩阵+队列——互不相同。
- 四项（骨架/字体/色彩/主视觉）两两至多一项相同（A 与 C 主字体同为雅黑，其余三项均不同）。
- 明暗不作为方向依据：A 暗是玄铁材质的结果；B/C/D 虽同为浅色但色相家族与材质感各异（纸墨 / 雾蓝档案 / 铝灰仪器）。
- 走到极端的一版：B（无图标、无圆角、点线引导，最不像现代工具 UI）。
- 打破品类套路的一版：B（不用彩色图标宫格，用文字目录页——与"提取目录"功能形成产品自我隐喻）。

## 假设与说明

- 小样内文件名、页数、时间、引擎状态均为**模拟数据**；状态（Office 已连接、LibreOffice 未安装、AI 未配置、OCR 就绪）是按功能清单 P0 设定的真实初始状态形态。
- 字体使用 Windows 系统字体栈，未引入网络资源；上线时可换思源黑体/宋体并打包。
- 组装对比页的生成器需要 Python 3，本机暂缺（见交付说明）。
- 验收重点：1280×900 下中文可读性（13px+ 正文）、四版"盲看"气质差异、引擎状态的表达方式是否让你安心。
