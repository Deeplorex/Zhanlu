# PDF 页面整理开发提示词

2026-11-24。以 `06 · 现行交互改版` 的 137–168 为页面操作基线。交互规则与调研见[页面整理设计索引](./README.md#2026-11-24-pdf-页面整理)和[交互说明](./interaction-2026-10.md#页面与拆分)。

- 从 `apps/web/src/features/pages/PagesGrid.tsx` 和 `apps/web/src/styles/theme.css` 的页面网格入手。沿用当前 PDF 标签、1280 px 六列和 840 px 四列，常驻操作栏，底部显示草稿摘要、撤销、取消变更及另存。横竖预览和待应用旋转沿用 131–132 的等比适配规则。打开[现行画板索引](./README.md#2026-11-24-pdf-页面整理)和[操作规则](./interaction-2026-10.md#页面与拆分)逐屏对照。
- 将网格位置、源页引用和页面实例 ID 分开。实例记录当前 PDF 页、已登记的导入 PDF 页或空白页尺寸，以及待应用旋转。源页引用用于取真实缩略图，位置用于显示当前页码和指定插入点，实例 ID 用于选区、拖动、焦点和撤销。复制分配新的实例 ID，继承复制当时的旋转，后续旋转与删除独立生效。移动使用稳定的锚点实例并保留组内顺序。撤销恢复上一步的页序和选区，取消变更清空撤销记录并恢复原始页序。
- 通过现有受信任的本机文件选择登记导入源，选择后留在整理面板。复用引擎页范围解析校验，空范围按原顺序插入全部页，非空范围按填写顺序取页且必须解析出有效页。导入取消、读失败或权限受限时保留草稿且不加入页面。空白页继承位置参考页的当前显示宽高，在开头或末尾分别取第一张或最后一张。
- 复用 `engine/zhanlu/jobs.py` 的 `organize` 及 `engine/zhanlu/core/pdfops.py`。预览与生成共用页面计划校验与页数、变更摘要计算。兼容既有 `{page, rotate}` 条目，扩展计划通过文件 ID 引用导入 PDF，并可表达同源页的多个实例和空白页。生成前重新核验文件可读性、目标整理权限、导入源提取权限、页号、旋转及保存位置。复制与导入保留 PDF 页面内容，单独应用各实例旋转。
- 点击生成时冻结对应草稿和输出参数，以任务实际结果更新完成状态。沿用 `useJob("organize")` 的预览、取消及任务反馈，继续使用现有防覆盖交付路径。取消或失败保留草稿和参数。成功只清除对应草稿的未应用状态，后续编辑重新标记。保留 `pagesDirty` 驱动的已保存版本打印提醒和关闭标签保护。
- 用真实横竖混排 PDF 串测空白页、另一份 PDF 的非连续页、批量复制、独立旋转副本、非连续多选移动、删除、撤销和另存。四页样本中，在原第 2 页后插入空白页，再在空白页后插入补充 PDF 的第 2、4 页。复制原第 3 页，将副本独立右转后移动到原第 2 页前，并删除原第 4 页。预期另存 7 页，顺序为原第 1 页、旋转副本、原第 2 页、空白页、导入第 2 页、导入第 4 页、原第 3 页。
- 用第二个阅读器对照页数、顺序、方向及文字，检查输入和已有文件原样保留。补测单页全删、越界、权限、源文件失效、同名输出、取消、失败重试，以及两种窗口尺寸下的鼠标与键盘焦点。记录 [P04](../../product/mvp-v1/acceptance.md) 验收结果和截图。
