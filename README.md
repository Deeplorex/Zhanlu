# 湛卢 Zhanlu

湛卢是面向 Windows 的本地优先 PDF 工作台，用于阅读文档、整理页面、转换格式，以及借助 OCR 和 AI 查阅内容。

## 产品介绍

- **阅读**支持 PDF 多标签、目录、全文搜索、全屏预览与放映。OFD 可打开预览并另存为 PDF。
- **页面整理**支持插入空白页或另一份 PDF 的指定页、复制、删除、拖动或按页码移动，以及旋转。可撤销变更，并在另存前核对结果。也支持按范围拆分和合并多份 PDF。
- **格式转换**支持 PDF 导出为图片、文本和 Markdown，提供基础 Word、Excel、CSV、PPT 导出，也可将多张图片合成 PDF。
- **OCR 与 AI 阅读**支持将扫描件识别为可搜索的 PDF，并提供带原文页码引用的摘要和问答。OCR 与本地模型按需安装，使用远程模型时由用户逐文档确认发送的文字范围。

文件处理在本机执行，结果另存，原文件保留。 [产品定义](docs/product/mvp-v1/README.md)

## 架构

| 层 | 技术与职责 |
| --- | --- |
| 桌面壳 `apps/desktop` | Rust 与 Tauri 2，负责 Windows 窗口、文件关联，以及启动和管理本地引擎。 |
| 工作台 `apps/web` | React、TypeScript 与 PDF.js，负责文档标签、渲染、搜索、交互预览及任务状态。 |
| 本地引擎 `engine` | Python，负责文件登记、后台任务、页面处理、格式转换、OCR 与模型调用。 |

桌面壳启动引擎时建立带会话令牌的本机连接。工作台通过本地 API 使用已登记的文件，处理任务在引擎中生成并登记输出。 [架构文档](docs/architecture/mvp-v1.md)
